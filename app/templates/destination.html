Set up WordPress

  1. In WordPress, open Users ? Profile and create an application password for a user allowed to edit posts.
  2. Set WORDPRESS_URL (the HTTPS site root), WORDPRESS_USERNAME, and WORDPRESS_APPLICATION_PASSWORD in your local .env.
  3. Restart without --demo and check the connection.
  4. Open Blog Posts, choose a post, preview and approve it, then select Import to WordPress.

Select an existing WordPress author and categories on the import page. Create matching tags in WordPress first. Nothing is published automatically.

Article images retain source URLs. Set the featured image in WordPress after import. The description becomes the WordPress excerpt; SEO plugin fields are not set.
